## 🗂 community_mods
Modified or remixed versions contributed by the community.

## 📦 How to Contribute

### Option 1: Fork & Pull Request (Recommended for Most)
1. **Fork** the repository to your own GitHub account.
2. Create a new branch for your changes.
3. Add your files or make your edits.
4. Commit your changes with a clear message.
5. Submit a **pull request** to the `main` branch.

We'll review your submission and merge it if everything looks good!

### Option 2: Direct Contributor Access
If you plan to contribute regularly or prefer to upload directly:
- Send us a message via GitHub or LinkedIn with a short description of your intention.
- If accepted, we’ll add you as a collaborator with upload access.
